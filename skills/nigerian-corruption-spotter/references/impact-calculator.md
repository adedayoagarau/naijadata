# Impact Calculator Reference

## Quick Formulas

```
Schools built = Amount / ₦150,000,000
Students impacted = Schools x 240

Health centers = Amount / ₦150,000,000
Citizens covered = Centers x 10,000

Boreholes = Amount / ₦5,000,000
People with water = Boreholes x 500

Vaccinations = Amount / ₦15,000
Malaria treatments = Amount / ₦5,000
```

## Example: ₦1.3 Billion
- 8 primary schools (1,920 children)
- 8 health centers (80,000 people)
- 260 boreholes (130,000 with water)
- 86,666 vaccinations
- 260,000 malaria treatments
